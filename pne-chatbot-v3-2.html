Hinweis vor dem Start

Dieses Tool ist Teil einer Forschungsstudie der PH Freiburg und vermittelt Informationen zur Schmerzneurowissenschaft.

  • Das Tool stellt keine Diagnosen und ersetzt keine Therapie.
  • Deine Fragen werden an einen KI-Dienst gesendet. Es werden keine personenbezogenen Daten dauerhaft gespeichert.
  • Bei Verschlechterung deiner Beschwerden: Therapeutin / Arzt kontaktieren.
  • Du kannst das Gespräch jederzeit beenden.

Mit dem Start stimmst du der Nutzung im Rahmen dieser Studie zu.
