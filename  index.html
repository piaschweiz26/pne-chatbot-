Hinweis vor dem Start

Dieses Tool ist Teil einer Forschungsstudie der PH Freiburg. Es vermittelt allgemeine Informationen zur Schmerzneurowissenschaft (Pain Neuroscience Education).

  • Das Tool stellt keine Diagnosen und ersetzt keine ärztliche oder therapeutische Beratung.
  • Deine Fragen werden an einen KI-Dienst gesendet. Es werden keine personenbezogenen Daten dauerhaft gespeichert.
  • Bei Verschlechterung deiner Beschwerden wende dich bitte an deine Therapeutin oder deinen Therapeuten.
  • Du kannst das Gespräch jederzeit beenden.

Mit dem Start stimmst du der Nutzung im Rahmen dieser Studie zu.
